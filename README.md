# Структуры данных на C++

![Стек](https://img.shields.io/badge/C%2B%2B17-334155?style=flat-square) ![Семестр](https://img.shields.io/badge/семестр-3-0f766e?style=flat-square) ![Статус](https://img.shields.io/badge/статус-%D0%A3%D1%87%D0%B5%D0%B1%D0%BD%D1%8B%D0%B9%20%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82-64748b?style=flat-square)

Лабораторная №1: собственные реализации базовых структур данных и консольное меню для работы с ними. Есть операции добавления, удаления, поиска и сохранения данных в файлы.

## Структуры

| Реализация | Файл |
|---|---|
| Динамический массив | [Array.h](Array.h) |
| Односвязный и двусвязный списки | [LinkedList.h](LinkedList.h), [DoublyLinkedList.h](DoublyLinkedList.h) |
| Стек и очередь | [Stack.h](Stack.h), [Queue.h](Queue.h) |
| Хеш-таблица | [HashTable.h](HashTable.h), [HashTable.cpp](HashTable.cpp) |
| Полное бинарное дерево | [CompleteBinaryTree.h](CompleteBinaryTree.h) |

## Сборка и запуск

```bash
c++ -std=c++17 main.cpp HashTable.cpp -o structures
./structures
```
